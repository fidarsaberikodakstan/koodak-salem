# کودک سالم + کودکستان — بستهٔ آغازین سامانه

این پروژه یک نسخهٔ آغازین فراتر از صفحهٔ معرفی ساده است: نمای کودک، نمای سامانهٔ مرکزی، نمای والدین، مدیریت نمایشی درس‌ها و ساختار پیشنهادی پایگاه داده را کنار هم دارد.

## شروع فوری
1. ZIP را استخراج کنید.
2. `index.html` را باز کنید؛ نسخهٔ آزمایشی در مرورگر اجرا می‌شود.
3. در سربرگ بین «اپلیکیشن کودک»، «سامانهٔ مرکزی» و «والدین» جابه‌جا شوید.
4. در «سامانهٔ مرکزی → درس‌ها» می‌توانید درس اضافه، ویرایش، پنهان یا حذف کنید. این تغییرات فقط در همان مرورگر ذخیره می‌شوند.

## انتشار رایگان وب
پیشنهاد: GitHub برای نگهداری کد + Cloudflare Pages برای میزبانی وب ثابت.
1. در GitHub یک repository بسازید و محتویات پوشه را در آن بارگذاری کنید.
2. در Cloudflare Pages، ایجاد پروژه از Git را انتخاب و repository را متصل کنید.
3. برای این نسخهٔ HTML خالص، build command لازم نیست؛ build output directory را `/` یا ریشهٔ پروژه تنظیم کنید.
4. پس از انتشار، نشانی آنلاین دریافت می‌کنید.

راهنماهای رسمی:
- https://pages.cloudflare.com/
- https://developers.cloudflare.com/pages/get-started/
- https://github.com/

## اتصال سامانهٔ واقعی
فایل `supabase/schema.sql` طرح اولیهٔ جدول‌ها و سیاست‌های امنیتی را دارد. برای مرحلهٔ بعد:
- پروژهٔ Supabase بسازید.
- SQL را پس از بازبینی در SQL Editor اجرا کنید.
- ورود واقعی، ایجاد امن حساب مدیر اصلی، دعوت معلم، اتصال فرزند به والد، و API امن را اضافه کنید.
- هرگز کلید service-role را در JavaScript مرورگر قرار ندهید.

## آنچه هنوز نسخهٔ نمایشی است
- ورود/ثبت‌نام واقعی، مجوزهای واقعی و احراز هویت هنوز متصل نیست.
- درس‌ها و پیشرفت‌ها در localStorage مرورگر ذخیره می‌شوند، نه روی سرور.
- دکمه‌ها و گزارش‌ها تا زمان اتصال پایگاه داده فقط برای نمایش هستند.
- محتوای وضو و نماز صرفاً نمونهٔ آموزشی است و پیش از انتشار عمومی باید توسط عالم واجد صلاحیت در فقه حنفی بررسی شود.
- صوت‌ها، انیمیشن‌های واقعی و محتوای کامل پشتو/فارسی/انگلیسی هنوز باید تهیه شوند.

## معماری پیشنهادی نسخهٔ کامل
- برنامهٔ کودک: PWA سازگار با موبایل/تبلت/کمپیوتر
- سامانهٔ مرکزی: مدیر اصلی، معلم‌ها و مدیریت محتوا
- پنل والدین: مشاهدهٔ فرزند پیوندخورده فقط
- Supabase Auth + Postgres + Row Level Security
- محتوای چندزبانه، فایل‌های صوتی، درس‌های آفلاین و ثبت پیشرفت
- حداقل‌سازی داده‌های کودکان و رضایت والدین

این بسته به‌تنهایی هنوز سامانهٔ تولیدی امن نیست؛ قبل از وارد کردن اطلاعات واقعی کودکان، باید اتصال سرور، سیاست‌های امنیتی و جریان ثبت‌نام آزمایش و بازبینی شوند.
